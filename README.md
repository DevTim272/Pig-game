## THE GAME

Pig Game is a simple but strategic dice game where every roll is a decision.

Keep rolling to build up your turn score, or hold to secure your points. Roll a one, however, and you lose everything accumulated during that turn.

The goal? Reach the winning score before your opponent does.

## HOW IT WORKS

| ACTION | RESULT |
|---|---|
| Roll Dice | Add the dice value to your current score |
| Roll a 1 | Lose your current turn's points |
| Hold | Add your current score to your total |
| Reach the target | Win the game |

## GAME FEATURES

- Two-player turn-based gameplay
- Random dice rolls
- Current score and total score tracking
- Automatic player switching
- Win detection
- New game and score reset functionality

## BUILT WITH

**JavaScript** — Game logic, player turns, scoring, and event handling.

**HTML5** — Game interface and structure.

**CSS3** — Layout, visual styling, and player states.

## RUN IT LOCALLY

You don't need a framework or package installation to run the standard version.

```bash
git clone https://github.com/DevTim272/Pig-game.git
```

1. Open the downloaded project folder.
2. Open `index.html` in your browser.
3. Start playing.

You can also use the Live Server extension in VS Code.
